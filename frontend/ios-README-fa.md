# اپ آیفون openGym

openGym روی آیفون هم به‌صورت اپ بومی (Native) اجرا می‌شود — همان کد فرانت‌اند
(React + Vite) داخل یک پوسته‌ی Capacitor قرار می‌گیرد. این فایل توضیح می‌دهد
اپ آیفون چیست، چطور ساخته می‌شود و چطور نصبش کنی.

## اپ آیفون چطور کار می‌کند؟

به‌صورت پیش‌فرض **کاملاً محلی** است؛ یعنی بدون سرور:

- **بدون حساب و ورود:** گوشی خودش حساب است؛ صفحه‌ی ورود و پسکی ندارد.
- **داده روی گوشی می‌ماند:** همه‌چیز (تمرین‌ها، برنامه‌ها، تنظیمات) فقط روی
  خود آیفون ذخیره می‌شود و بعد از هر تغییر، یک کپی بادوام هم در فایل
  `opengym-state.json` در حافظه‌ی خصوصی اپ نوشته می‌شود (iOS گاهی حافظه‌ی
  WebView را پاک می‌کند؛ این فایل نسخه‌ی مطمئن است و موقع باز شدن اپ
  برگردانده می‌شود).
- **پشتیبان از طریق Share Sheet:** خروجی پشتیبان (JSON یا zip همراه عکس و
  ویدیو) از مسیر Settings → Data و با دکمه‌ی اشتراک‌گذاری iOS بیرون می‌رود.
- **یادآوری‌ها محلی‌اند:** اعلان‌های بومی (Local Notifications) بدون سرور.
- **عکس و ویدیوی تمرین‌ها از CDN می‌آید:** چون سروری در کار نیست، تصاویر و
  گیف‌های تمرین‌های آماده از jsDelivr خوانده می‌شوند (نه از سرور خودت).

## اتصال به سرور خودت (اختیاری)

اگر سرور openGym خودت را داری، می‌توانی اپ را به آن وصل کنی تا داده‌ها
همان‌طور که در نسخه‌ی مرورگر همگام می‌شود، بین گوشی و سرور همگام شود. این یک
حالت از همان اپ است، نه یک نسخه‌ی جدا:

1. در مرورگری که وارد حسابت شدی، به Settings → ‏«Pair the mobile app»‏ برو؛
   یک کد یک‌بارمصرف می‌گیری که ۵ دقیقه اعتبار دارد.
2. در اپ (همان صفحه‌ی اول یا Settings → ‏«Connect to my server»‏)، آدرس سرور
   و آن کد را وارد کن.

نکته‌ها:

- پسکی (Passkey) داخل اپ کار نمی‌کند؛ چون WebView اپ آدرس سرور واقعی را
  ندارد. به‌جای آن، اتصال با کد یک‌بارمصرف و بعد با یک توکن انجام می‌شود.
- آفلاین هم کار می‌کند: تغییرات بدون اینترنت روی گوشی می‌مانند و به‌محض
  وصل‌شدن به سرور می‌روند.
- اگر می‌توانی، آدرس سرور را **HTTPS** بده؛ توکن از راه سربرگ (header)
  ردوبدل می‌شود.
- **هنوز راه‌اندازی نشده:** سرور openGym بابا جون هنوز دپلوی نشده؛ اتصال به
  سرور یک قدم جداست و اول باید سرور بالا بیاید.

## ساخت IPA

### با GitHub Actions (توصیه‌شده — نیازی به مک نداری)

ورک‌فلو `.github/workflows/build-ios-ipa.yml` روی `macos-latest` اجرا می‌شود:

1. `npm ci` در `frontend`
2. `npm run build:mobile` (باندل موبایل + `cap sync`)
3. `xcodebuild archive` **بدون امضا** (`CODE_SIGNING_ALLOWED=NO`)
4. بسته‌بندی `Payload/App.app` به‌صورت `openGym-<version>-unsigned.ipa` و
   فایل `.sha256` کنارش

خروجی در بخش Artifacts همان اجرای ورک‌فلو قابل دانلود است (۳۰ روز می‌ماند).
اجرا یا دستی است (Actions → Build iOS IPA → Run workflow) یا با هر تغییری
در `frontend/ios/**` خودکار انجام می‌شود.

> **هنوز روی GitHub Actions تست نشده:** اولین اجرای این ورک‌فلو روی مک
> گیت‌هاب هنوز انجام نشده؛ مثل شغل `build:ios` در GitLab که هنوز اجرا نشده،
> ممکن است دور اول چند اصلاح کوچک لازم داشته باشد (مثلاً نسخه‌ی CocoaPods
> یا Xcode روی رانر).

### روی مک خودت (Xcode + CocoaPods)

```sh
cd frontend
npm install
npm run build:mobile        # باندل موبایل + cap sync (روی مک، pod install هم اجرا می‌شود)
npx cap open ios            # باز شدن در Xcode → تیم امضا را Apple ID خودت بگذار و اجرا کن
```

نیازمند مک با Xcode 15 به بالا و CocoaPods (`brew install cocoapods`) و
حداقل iOS 15.5 روی گوشی.

## نصب با AltStore

اپل اجازه‌ی نصب مستقیم IPA خارج از App Store را نمی‌دهد؛ AltStore با
امضای رایگان Apple ID این کار را می‌کند:

1. فایل `openGym-<version>-unsigned.ipa` را از Artifacts ورک‌فلو دانلود کن.
2. روی آیفون **AltStore** و روی کامپیوتر (ویندوز یا مک) **AltServer** را نصب
   کن؛ هر دو باید روی **یک Wi-Fi** باشند.
3. در AltStore به My Apps → دکمه‌ی `+` برو، فایل IPA را انتخاب کن و با
   Apple ID خودت (حساب رایگان کافی است) وارد شو.
4. آیکون openGym روی صفحه‌ی اصلی آیفون می‌آید.

**مهم — امضا ۷ روزه است:** امضای Apple ID رایگان بعد از ۷ روز منقضی
می‌شود. AltStore وقتی AltServer روی همان Wi-Fi در حال اجراست، به‌صورت
خودکار در پس‌زمینه دوباره امضا می‌کند؛ اگر AltServer خاموش بود یا
دستگاه چند روز به Wi-Fi خانه وصل نشد، از داخل AltStore دکمه‌ی Refresh را
بزن. جایگزین AltStore: ‏Sideloadly‏ (با کابل USB، همان امضای ۷ روزه).

## نکته‌های دیگر

- اپ در App Store و TestFlight نیست — به‌عمد؛ بدون حساب توسعه‌دهنده و
  بدون قانون فروشگاه.
- نسخه‌ی آیفون همان نسخه‌ی اندروید است (`package.json` نسخه‌ی ۱٫۳٫۹،
  شماره‌ی بیلد = `versionCode` اندروید، فعلاً ۲۳).
- اگر به‌جای اپ بومی، نسخه‌ی تحت وب را می‌خواهی: سرور را در Safari باز کن،
  Share → ‏Add to Home Screen‏ — تمام‌صفحه اجرا می‌شود و منقضی نمی‌شود؛
  ولی برای آن هم اول باید سرور بالا باشد.

جزئیات کامل‌تر در `docs/MOBILE.md` (انگلیسی) هست.
