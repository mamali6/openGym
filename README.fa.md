# 🏋️‍♂️ openGym (نسخه فارسی - Persian Edition)

یک سامانه جامع، مدرن و سلف‌هاستد (Self-Hosted) برای ثبت، مدیریت و تحلیل هوشمند تمرینات بدنسازی و وزن بدن با تمرکز بر حفظ حریم خصوصی، عملکرد آفلاین و بدون هیچ‌گونه تبلیغات یا هزینه اشتراک.

---

### ✨ قابلیت‌ها و ویژگی‌های کلیدی:

* 🇮🇷 **پشتیبانی کامل از زبان فارسی و راست‌چین (RTL):** ترجمه جامع تمامی اصطلاحات فیتنس، سیستم‌ها، حرکات و تاریخ خورشیدی (شمسی) با تایپوگرافی زیبای فونت وزیرمتن (Vazirmatn).
* 📱 **تجربه وب‌اپلیکیشن پیش‌رونده (PWA):** عملکرد ۱۰۰٪ آفلاین بر روی گوشی‌های آیفون و اندروید، روشن ماندن صفحه حین تمرین و واکنش‌گرایی بالا.
* 🤸‍♂️ **بانک اطلاعاتی بیش از ۱,۳۲۰ حرکت ورزشی:** همراه با دموهای متحرک (GIF)، راهنمای گام‌به‌گام و تفکیک آناتومیک عضلات درگیر.
* 📊 **تحلیل هوشمند و نقشه خستگی بدن:** ردیابی بار عضلانی، ریکاوری، حجم تمرین، و تخمین رکورد حداکثر (1RM).
* 🔐 **امنیت و حریم خصوصی:** ورود با اثر انگشت یا فیس‌آیدی (Passkeys / WebAuthn)، رمز عبور یا حالت مهمان محلی (بدون نیاز به ثبت‌نام).
* 🤖 **سازگاری با هوش مصنوعی و MCP:** دارای سرور اختصاصی Model Context Protocol (MCP) جهت اتصال به مدل‌های زبانی بزرگ برای ارائه برنامه تمرینی و نقش مربی ورزشی هوشمند.
* 🔄 **انتقال آسان دیتا:** امکان ایمپورت مستقیم تاریخچه از اپلیکیشن‌های Strong، Hevy و FitNotes به همراه خروجی گرفتن JSON.

---

### 🚀 راه‌اندازی سریع با داکر (Docker Compose):

```bash
# کلون مخزن
git clone https://github.com/mamali6/openGym.git
cd openGym

# تنظیم فایل متغیرهای محیطی
cp .env.example .env

# بیلد و اجرای کانتینرها
docker compose up -d --build
```
